# dsh-thoughtdag · DSH 会话主干图

当前源码版本 **0.4.14-rc2.10**，目标宿主 **DeepSeek Harness 0.1.5-rc.2**。插件在真实会话标题栏提供 **对话 / 思维图** 切换，把上下文来源组织到接收会话自己的主干中。每次回答仍在原生会话中进行，由用户发送。

这是 [ThoughtDAG 定制分支](../README_ZH.md)的插件包。下面介绍当前代码和已验证的本地组合，不表示同版本 npm 包或公开下载附件已经发布。上游包名、上游下载链接和 `@latest` 不能替代这个组合。

## 配套环境

| 组件 | 当前配套源码版本 | 用途 |
|---|---|---|
| DeepSeek Harness | 0.1.5-rc.2 | 原生工作区、会话、输入框与模型执行 |
| Maintenance 插件 / Engine | 0.2.26-rc2.19 / 0.1.33-rc2.23 | 稳定会话身份、图协议 2、固定源读取、撤销与归档 |
| Annotation Core | 0.3.12-rc2.12 | 统一引用准备、发送状态和已发送引用恢复 |
| ThoughtDAG | 0.4.14-rc2.10 | 主干图 UI 与原生会话入口 |
| Session Sticker Board | 0.7.3-rc2.18 | 会话贴纸及来源蓝色引用入口；使用这些入口时需要 |

所有服务必须指向同一 DSH 实例。Obsidian 笔记关联还需要配套 Lifecycle、Reference Adapter 与 Vault 伴侣插件；基础主干图不要求打开 Obsidian。组件以实际能力检查为准，缺少协议或版本不匹配时会显示错误，不回落到旧写入接口。

## 构建与安装本地包

Node 要求是 **22.x 的 22.19 及以上版本，或 24 及以上版本**。在仓库根目录：

```sh
npm ci
npm run dsh:build
cd dsh
npm pack
```

`npm pack` 也会执行插件构建，产物为当前目录中的 `dsh-thoughtdag-0.4.14-rc2.10.tgz`，包含嵌入 SPA、宿主入口和客户端入口，不需要另装 ThoughtDAG 桌面版。

使用 Launcher 时，在目标实例中更新配套本地包，并保留已配置的 Suite 父子加载关系。使用 CLI 时，先切换到目标实例原有的 Home/profile 环境并准备好上表依赖；在刚才的 `dsh` 目录安装本地文件：

```sh
dsh plugin --profile web add ./dsh-thoughtdag-0.4.14-rc2.10.tgz
```

随后按该实例原有方式重启 DSH，刷新浏览器页面。这个命令只安装 ThoughtDAG，不能代替 Maintenance Engine 的配置，也不会自动取得尚未公开发布的配套 RC2 包。

## 从图进入真实会话

1. 在会话标题栏选择 **思维图**，复用该接收会话的主干。
2. 右键空白处，添加空卡片或按“工作区 → 已有会话”选择卡片。仅添加卡片不会创建引用权限。
3. 右键卡片选择 **在此节点开始会话**。空卡片会先选工作区、确认创建，取消不创建；已绑定卡片打开原会话。创建请求超时重试会保留原工作区意图。
4. 从来源拖线到接收节点，或选择 **连接到节点**，确认已完成回复与固定版本。未绑定节点之间只保存待绑定连接。
5. 回到原生会话检查引用和输入内容后发送。已有正文、草稿与附件保留，不自动发送，也不在图上启动独立问答。

X → Y 的引用属于 **Y 的主干**。自动布局让 X 位于 Y 上方，连接点在卡片上下，多父来源横向分布；已有位置保留，可用 **按来源排列** 主动重排。面板配色、字体、明暗模式和视图开关位置跟随 DSH。

| 操作位置 | 功能 |
|---|---|
| 空白右键 | 添加空卡片、添加已有会话、按来源排列、适合画布、关联已有对象、导入当前目标已有引用 |
| 卡片右键 / ⋯ | 在此节点开始会话、查看来源、连接到节点、重命名、移除卡片 |
| 边右键 | 查看固定来源与读取位置、确认待绑定连接来源、移除边 |

键盘支持 Shift+F10 打开菜单、方向键切换、Escape 关闭、Delete/Backspace 移除选中对象。窄屏也可从 **画布更多操作** 进入。

## 会话与思维图切换

思维图沿用会话内容区域的左边界和顶部边界，标题栏的对话／思维图开关保持原位。面板显示与隐藏使用短时透明度和位移动效；系统启用减少动态效果时立即切换。连续切换会从当前状态接续，不需要等前一段动画完成。

图的嵌入页面在当前会话内复用，切回对话后不会因为动画反复挂载。画布卡片、连线与引用的保存规则保持不变；界面切换不发起模型请求。

## 固定范围与读取日志

每条引用绑定来源版本及已完成回复截止。来源追加新消息不会扩大旧引用；首轮材料在预算内包含所选回复所在问答，较早历史通过工具按需读取。图保存结构、范围与位置，不复制完整会话历史。

**查看来源** 是只读弹层，多引用可选固定范围，翻页保持同一版本。选文可继续制作材料卡、引用到会话或建立会话贴纸。

**查看固定来源与读取位置** 显示允许截止、实际返回范围、继续位置、预算、截断与交付状态。已准备不等于已交付；搜索命中不等于读完整篇；用户预览不计作 AI 已读。来源不可用或已撤销时明确失败，不改读最新版本。

## 删除、归档与故障恢复

- 移除卡片、边、键盘所选对象共用后端撤销操作，保留真实会话及既有回答。草稿气泡清理失败时有单独重试入口。
- Sticker 蓝色符号右键可以删除指定引用。引用变化、会话列表变化、面板重开及窗口恢复会触发图同步；图可见时每 10 秒补充核对，保留未保存布局。
- 归档会话撤销相关活动引用、清除相关待绑定边，并使自身主干只读。当前布局可另存为无引用权限的草稿。恢复会话只恢复因归档而隐藏的自身主干，不恢复已撤销引用、连接或手动删除的图。
- 开始会话失败可 **刷新引用并重试开始** 或 **返回对话检查**；同一引用的固定版本和目标身份不会因重试改变。已发送引用的轻量授权由配套 Core 从目标范围内的 Maintenance 记录恢复，不重复发送或补造提交回执。
- 保存冲突保留本地修改。**保留布局副本并重新载入** 会另存不带活动权限的草稿，再读取权威主干。

旧图迁移、显式导入已有引用、对象关联与完整边界见 [MANAGED.md](MANAGED.md)。独立 ThoughtDAG 的 Session Atlas、模型代理、画布问答属于仓库 [standalone 应用](../README_ZH.md#独立应用)，不属于本嵌入入口。
