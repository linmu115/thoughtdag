工作区服务就绪、等待超时或插件卸载后，等待器必须释放对应的注入 fiber 和定时器。已经就绪时直接读取。超时仍可使用原有会话 cwd 兜底；没有归属信息则明确失败。

卸载应取消本插件的网络请求，并阻止已经返回的旧请求继续发起引用修改、会话刷新、打开或界面回传。此前已经交给其他服务执行的动作不自动撤销，也不把取消当成操作回滚。

保持插件职责和现有数据合同；不改变 Core 的 required peer，不新增 Bridge 或 Maintenance 依赖。验收见 [[VER-client-lifetime-20260923]]。

主任务复查补充：Core 依赖切换时，旧引用操作必须失效，不能依靠服务代理对象相等判断。同一宿主上下文重载时重新构造图的数据端口。公共 `sessionWriteAccess` 从未出现时保持独立可写，一旦观察到出现，断开期间拒绝写入、读取继续；新提供者允许后恢复。此次授权取代 [[IMP-write-access-20260921]] 中 2026-09-21 暂不修复的阶段决定。
