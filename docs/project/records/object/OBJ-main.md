# 图、卡片、引用边各代表什么

以 X → Y 为例：Y 是接收材料并执行的会话，图属于 Y；X 是固定版本的上游来源。把 X 添加到画布只是卡片，必须完成连接确认才产生引用权限。

空卡片尚未绑定真实会话；待绑定连接不能读取上游。真正“在此节点开始会话”时才选择工作区并创建；成功后保存真实身份。

布局位置、标题、缩放与权限无关。图中读取覆盖也不是当前模型仍保留的材料：释放后历史覆盖仍在，实际保留可以减少。
