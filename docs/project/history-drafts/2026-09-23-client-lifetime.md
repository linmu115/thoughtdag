采用一次性依赖等待、挂载取消信号和异步边界检查，保留独立插件关系，不改变用户数据。首次定向客户端测试 8/8，全 DSH Node 测试 30/30；源码异步边界复查后再次执行最终验证。宿主注册返回值未取得独立实证，因此本次不改宿主路由。未部署、未做真实 UI 验收。

主任务审阅指出 add/stage/delete 在等待期间持有旧 Core 的缺口，并明确将可选写入许可服务的断开保护纳入本轮。按此采用实际注入生命周期代次而不比较代理对象，增加移除/重注册测试，34 项通过。进一步审计发现图端口以 ctx 为键缓存，主任务授权在 owner 生命周期结束时清理；同一 ctx 重挂测试证实新端口被调用，最终 35 项通过。
