# 会话与思维图：连续滑动选择器

## 需求与参考

参考用户指定的[方案切换组件教程](https://www.bilibili.com/video/BV1g3t96kEEF)。本次使用本地音频转写确认结构：固定标签、独立选中滑块、通过 transform 切换位置。没有逐帧视觉核对，因此不是对视频外观的逐像素复刻。

## 实现

- 对话与思维图使用等宽布局，文字与外框不随选中状态移动。
- 选中底块通过一个伪元素在两侧间滑动，持续 320ms；快速反向操作从当前进度折返，不排列待执行动画。
- 宿主标题栏与覆盖层开关同步状态与进度。覆盖层显示前提交起始位置，避免第一次出现就跳到终点。
- 原有视图淡入淡出、焦点恢复、侧栏和横线对齐、同一 iframe 复用保持。
- 配色读取 DSH 原生主题变量。开启系统“减少动画”时立即切换。
- 空闲时无动画循环；动效不读写会话、图对象、引用或 Vault。

仅有两个视图入口，因此没有新增教程中的子选项菜单。继续保留原生 button 的键盘和焦点行为；用现有视图状态管理代替另一套隐藏表单状态。

## 验证与交付边界

真实客户端 shim 加打包 SPA 的合成浏览器验证共 18 项通过，无页面错误。新增检查记录开关两侧的中间位移与快速折返，并检查切换前后 x、y、width、height 完全一致。原有明暗主题对比度、窄窗口、减少动画、图操作和草稿保留继续通过。
