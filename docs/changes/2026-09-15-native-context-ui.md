# 原生上下文管理面板

日期：2026-09-15。范围：ThoughtDAG 的受管 DSH 面板及用户桥接。本文不代表已安装到运行副本，版本与组合发布由联合交付单独记录。

## 行为

来源卡片右键“管理来源上下文”先选择连接。边的固定来源弹层显示授权范围、活动窗口、当前原生输入保留材料、实际操作回执，以及独立的历史读取覆盖。布局仍保持上下来源顺序，使用现有 DSH 主题变量。

用户请求索引按固定来源分页，只在展开后请求。长请求另页读取，问答仅在“查看这一问答”时通过 user-read 预览；收起取消未完成请求。不把目录预览记成模型阅读。选择稳定请求位置构成不连续窗口，扩大不自动载入全文，缩小安排释放；未提交计划不会被后台状态刷新覆盖。

暂停可显式选择同时释放；恢复不会预载历史。默认“释放此来源材料”使用 referenceId 放弃当前引用持有，其它持有者保留。按 materialIds 释放共享正文时，按钮明确列出影响的引用数量。用户固定项需先取消固定。操作显示待生效、已生效、失败或不支持；不以删除气泡或保存意图冒充实际释放。

浏览其它主干时不使用当前会话身份误改它；要求先进入其所属会话。桥接只允许已列出的领域操作，拒绝 payload 覆盖 actor、run、owner、instance 等身份。调用 Maintenance 的 requestAsUser，由 Host 固定操作方及当前原生会话。缺少协议 1 能力显示明确禁用状态。操作冲突保留计划；网络、5xx 或无法判定的结果保留操作身份供核对，不盲目生成新操作覆盖。

## 验证

- TypeScript 构建检查。
- Managed bridge、client、model、同步测试：身份伪造拒绝、同源约束、缺能力拒绝、固定范围和取消。
- `node --test src/maintenance/source-context-ui.test.mjs`：真实 Headless Edge 加合成 HTTP 状态，验证不连续窗口、按需问答预览、pin、待生效释放、暂停不暗含释放、计划保留、同身份重试、缺能力禁用和共享来源释放路径。无真实会话、模型请求或用户数据修改。
- 运行副本及原生 surface 的联合验收不由这组 UI 测试替代。

## 维护入口

- `src/maintenance/SourceContextPanel.tsx`：集中式来源面板与目录/问答分页。
- `src/maintenance/client.ts`、`dsh/lib/managed-graph.js`：同源当前会话桥接。
- `src/maintenance/ManagedGraphApp.tsx`：来源入口、归属约束和模型修改刷新。
- DTO 直接引用 Maintenance contracts，不在此复制权限或材料状态合同。
