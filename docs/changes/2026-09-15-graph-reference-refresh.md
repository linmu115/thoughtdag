# 会话开始错误与引用同步

用户报告已绑定卡片“在此节点开始会话”返回：引用已发送，但当前实例缺少对应提交记录。调用链确认错误由 Annotation 的 `prepareGraphReferences` 返回；ThoughtDAG 没有把拒绝当作成功，也没有进入原生打开步骤。权威 sent 引用恢复由 Annotation Core 的配套修改处理。

ThoughtDAG 本次改动：

- 开始已有会话前重新读取权威图，稳定去重合法入向引用；排除已撤销、已移除及其它目标的引用。失败保留原始原因，提供重试和返回对话检查。
- 宿主转发 `dsh-session-references-changed`、会话列表变化和窗口恢复，面板重新显示及每 10 秒可见核对作为补充。
- 服务器引用和节点成员变化优先；三方合并保留未保存位置、名称、视口、新卡片及待绑定连接。异步核对不覆盖执行中的修改。
- `graph.archivedAt` 使打开中的归档主干只读，保留布局，停止开始与编辑。归档状态不再请求被禁止的引用目录；恢复后重新核对，不复活已撤销引用。可把布局另存为无活动权限的草稿。
- HTTP 超时和连接中断提供可恢复说明，保留修订比较与权限校验。

验证：35 项模型、客户端、HTTP 宿主及浏览器 shim 的合成测试通过；覆盖精确删除后同步、同源另一条引用保留、未保存布局、归档恢复、错误透传及先准备后打开。修改的 TypeScript 文件 ESLint 通过，DSH SPA 构建通过。浏览器交互与整组安装由主任务验收；本次没有运行外部浏览器脚本、修改版本、提交或操作真实会话数据。
