# 思维图边界对齐与连续动效

日期：2026-09-15。ThoughtDAG 插件 0.4.14-rc2.10；配套 Maintenance 插件 0.2.26-rc2.19 / Engine 0.1.33-rc2.23。

## 可见变化

原面板使用固定左栏宽度，并在顶部额外预留开关空间；切换后主横线与左竖线因此偏离会话页。现在从插件所在的原生语义 header 测量左边界、下边界及开关位置，统一驱动画布导航和紧凑标题栏，不依赖生成的 CSS 类名。侧栏缩放、折叠到 56px、标题宽度变化及窗口变化都会重新核对几何位置。折叠模式保留原生窄栏的占位，主干导航通过抽屉打开，打开抽屉不推动画布。

对话和思维图切换使用 180ms 透明度过渡，画布内容仅有 4px 的轻微位移；两条边线与开关保持原位。连续反向点击直接从当前透明度接续，不排队播放。开启减少动画时立即切换。

空画布提供添加空卡片、按工作区选择已有会话的直接入口。加载期间显示真实读取状态；卡片、连接与选中数量位于画布角落，方向说明和快捷键通过“图示与操作”按需展开。右键菜单使用实际尺寸限制到视口内，支持方向键、Home、End、Tab 和 Escape，关闭后返回触发位置；菜单内 Delete 不会误删图上的选中对象。

## 性能与生命周期

- 同一 iframe 仅首次加载；切换不重新挂载画布，不清除未提交布局或会话草稿。
- 透明度与位移由浏览器合成，未添加逐帧宽高布局、全画布模糊或永久动画循环。合成层提示只在过渡期间保留。
- 关闭立即让画布停止可见状态的刷新，并在淡出后隐藏；子页面 ready 握手只回放最新状态，移除过去无条件延迟发送 shown=true 的回调。
- 几何观察采用已有 ResizeObserver 和一次动画帧合并，未加全页面 DOM 内容扫描；相同 CSS 值不重复写入。
- 显示图时暂时禁止背景接收焦点和交互；返回时恢复背景原状态与开关焦点。卸载清理观察器、事件监听和未结束的定时器。

这些是实现边界与合成行为验证，并非对用户设备的 GPU 帧率或 Obsidian 偶发卡顿作性能保证。

## 验证范围

使用打包后的真实 SPA、父页面插件及合成宿主会话验证主流程。浏览器场景覆盖展开侧栏、缩放侧栏、56px 折叠栏、标题变宽、动态 header 高度、明暗主题和 390px 窄屏；逐项核对主横线、左边界和开关矩形。连续切换验证中间透明度、iframe 文档身份复用、最终隐藏状态、背景交互恢复、焦点恢复及原草稿保留；减少动画模式验证立即关闭。

另有加载、空态、工作区选择和窄屏菜单的独立行为测试。原有固定版本读取、引用准备、图撤销、冲突恢复、原生上下文与来源保护回归继续执行。真实副本安装、HTTP 资产和运行状态由单独部署记录确认；合成界面验收不冒充真实用户图上的鼠标全流程。

最终 DSH 构建通过，47 项自动测试全部通过（无失败、无跳过），打包界面的 17 项浏览器检查全部通过且无页面错误。TypeScript 与本次变更的 ESLint 检查通过。菜单焦点测试覆盖节点测量时短暂不可见，以及用户主动转移焦点后不被抢回的情况；恢复处理可取消且最多持续 200ms。截图等待动画结束，动画本身仍在普通运动模式下单独验证。
