# 上下布局与 DSH 主题

DSH 插件版本：0.4.14-rc2.7，目标 DSH 0.1.5-rc.2 副本。

自动新增的会话贴纸和跨会话引用采用从上到下的上下文方向：来源 X 位于接收会话 Y 上方，同链横坐标对齐。多个来源占用同一上层的空闲列。前后端统一行距 260px、列距 320px；普通新增卡片默认置于最下方卡片下面。明确指定的右键落点、手动摆放及已经保存的位置保持不变。已有图可使用“按来源排列”主动重排。

嵌入面板直接跟随同源 DSH 宿主的实际主题变量与字体，监听浅深色切换和切换按钮位置变化。按钮、弹层、卡片、网格、连线、缩放控件、来源预览、读取日志及侧栏使用同一主题。对话/思维图开关继续以原会话页按钮作为位置锚点。窄屏保留主干与草稿入口，菜单受屏幕边界约束。

独立 ThoughtDAG 的样式与外观偏好只由 standalone 入口加载；嵌入面板不读取或写入其偏好，避免米色/紫色及强制背景覆盖 DSH 深色。主题观察在页面退出和开发热替换时清理。

上下文授权、图协议 2、固定截止范围、披露预算和图对象归属不变。Maintenance 的权威默认布局与兼容版本同步更新，不对已有用户图执行批量迁移。

验证：28 项模型/客户端/宿主/主题测试通过，TypeScript 与 DSH 构建通过，相关 ESLint 无错误。合成浏览器验证了 X/Y 同横坐标、260px 行距、实际浅深色同步、来源弹层、390px 窄屏菜单不溢出和两视图开关位置一致，无页面错误和模型请求。
