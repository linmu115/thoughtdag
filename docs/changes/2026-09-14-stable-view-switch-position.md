# 切换视图时保持开关位置

DSH 插件 0.4.14-rc2.4。之前会话页开关随顶栏布局，画布页开关单独居中，导致点击切换后位置跳动。

画布开关现在使用当前会话顶栏开关的实际位置和尺寸。切换回对话沿用原来的顶栏布局；窗口大小、侧栏布局或滚动变化时重新对齐。关闭画布时停止尺寸观察，插件卸载时清理观察器及事件监听。画布仍复用原 iframe。

## 验证

- 20 项宿主测试通过。
- 8 项生产页面浏览器场景通过，包括切换前后横纵坐标、宽高比较，以及 1440、900、390 像素视口变化；允许的测量误差为 0.5 CSS 像素。
- 副本安装后另外比较真实 DSH 页面两端开关的位置。安装及实际验证回执位于 D:/AI/DeepSeekHarness-Plugin/artifacts/view-switch-position-20260914。

本次只调整开关布局，原生会话、引用和图结构的读写行为不变。
